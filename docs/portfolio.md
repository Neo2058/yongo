# Портфолио и скриншоты

Тексты трёх кейсов находятся в `src/content/projects.ts`. Страницы: `/work/arm`, `/work/desire-house`, `/work/yongo`.

## Добавление скриншотов

Положите PNG, JPG или WebP в соответствующую папку:

- `public/images/work/arm/`
- `public/images/work/desire-house/`
- `public/images/work/yongo/`

Используйте имена `01-overview.png`, `02-form.png`, `03-report.png`. Галерея подхватит изображения автоматически, в порядке имён. Пока файлов нет, пустая галерея не показывается. Клик открывает изображение целиком. Рекомендуемая ширина 1440–1920 px; по возможности до 500 КБ на изображение. В production новые файлы включите в новую сборку/образ.

Эти папки публичны. Добавляйте только подготовленные изображения с тестовыми данными. Проверьте имена людей, контакты, адресную строку, внутренние адреса и уведомления. Рабочие выгрузки и исходные снимки сюда не помещать.

Для ARM: обзор, планирование, обезличенный отчёт. Для desire-house: главная, услуга/проект, административная форма. Для Yongo: каталог, запрос и его запись в админке на тестовом окружении.

## CMS и обновление текстов

Вводный текст `/work` и страница `/about` остаются под управлением CMS. Если страницу `/work` снять с публикации, список и все страницы кейсов недоступны; кейсы также исчезают с главной и из sitemap. Тексты отдельных кейсов пока редактируются в файле, не в админке.

Новые установки получают новые услуги и страницы из сидов. Для существующей базы:

```
node --experimental-strip-types scripts/refresh-public-content.mjs
node --experimental-strip-types scripts/refresh-public-content.mjs --apply
```

Первый запуск показывает план. Второй создаёт резервную копию SQLite и обновляет только записи, полностью совпадающие со старыми публичными шаблонами. Отредактированные через CMS записи, закрытые материалы, заявки и заказы не меняются. Шаблонная услуга UE архивируется. Старые адреса остальных услуг сохраняются.

Перед отправкой сайта клиентам проверьте формы с тестовыми данными и получение почтового уведомления. На главной больше нет процентов навыков и коммерческих обещаний по UE/3D. Блог не переписывался: перед продвижением проверьте опубликованные статьи на актуальность.
